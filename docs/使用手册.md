# Claude Desk 使用手册

> Claude Desk 是一个把 **Claude Code（claude CLI）** 变成「桌面会话管理窗口」的应用。
> 它在你自己的机器上启动真实 claude 进程，负责会话管理、终端、上下文监控、纪要、配置管理，对话体验与终端里的 claude 一致。

---

## 1. 快速上手

1. 安装并打开 Claude Desk（首次会先显示启动页：应用 Logo + 加载动画）。
2. 在主界面新建一个会话：指定**工作目录**（claude 要在哪个项目里工作），可选填启动参数。
3. 点进会话即**自动打开真实终端**，直接在终端输入框里开始和 claude 对话。
4. 对话中的 `/权限确认`、`/retry`、`/rewind`、`Ctrl+C`、状态栏等行为和命令行里的 claude **完全一致**。

> 前提：机器上已安装 `claude` CLI（`claude` 在 PATH 中，或在「设置 → claude 可执行文件」里指定路径）。

---

## 2. 窗口与全局操作

### 顶部导航

- **工作空间**：会话列表页
- **设置**：主题、关闭行为、claude 路径、配置模板、配置文件等
- **全屏/还原**：进入/退出全屏（快捷键 `F11`）

### 退出行为（重要）

点窗口右上角 **X**（或 `Alt+F4`）默认是**退出**：

- 没有运行中的终端 → 直接退出
- 有运行中的终端 → 弹出确认框，点「确定关闭」才真正退出（避免误关把真实 claude 会话连带杀掉）

也可以改成**缩小到后台（托盘）**，见「设置 → 关闭行为」。

### 系统托盘

当「关闭行为」选择 **缩小到托盘** 时：

- 点 X 只把窗口藏到托盘，**进程、运行中的终端、后台任务全都不停**
- 左键单击托盘图标（或托盘右键菜单「打开 Claude Desk」）恢复窗口
- 彻底退出用托盘右键菜单「退出」

### 主题

「设置 → 界面主题」切换 **暗色 / 亮色**。窗口级（Windows 原生标题栏）会跟随一起变，无白条。

## 3. 工作空间（会话列表）

主界面即会话列表，全部会话都在这一页管理。

### 列表与筛选

- 顶部有筛选 tabs：**全部 / 今天 / 昨天**，后面跟一个**日期选择器**（可任选一天，选了日期优先于 tabs，旁边 ✕ 清除）
- 按更新时间倒序排列，每页 20 条，**按天分组**（今天 / 昨天 / M月D日（一周内）/ yyyy-MM-dd（更早）），组标题右侧显示该组会话数
- 超过一页时底部出现分页器：`← 上一页 / 第 x/y 页 · 共 N 条会话 / 下一页 →`，切页超界会自动落到最后一页

### 行内信息

- 左侧圆点表示运行状态：**运行中 = 绿色呼吸动画**，行右上角还有「运行中」标签（由主进程终端状态实时驱动，切回来即最新）
- `📁 工作目录`；若该会话**未跳过权限确认**会显示「⛔ 有权限确认」（表示 claude 执行工具时会逐条问你）
- 上下文占用 `已用 token / 窗口上限`，超出上限标红
- 创作 / 更新时间

### 操作

- **＋ 新建会话**（右上角或空状态处）→ 弹出新建表单，创建后自动进入该会话
- 行内 **⚙** 编辑（预填原值；运行中的会话会提示"改动将在下次重新打开终端时生效"）
- 行内 **🗑** 删除：先弹确认框（"删除该会话？运行中的任务会被终止"），确认后连带终止运行中的终端
- 没有会话时显示空状态引导 + 「新建会话」按钮

## 4. 会话

### 会话是什么

一个会话 = 「绑定一个文件夹 + 一组 claude 启动参数」的一次工作上下文。每个会话可以打开**一条真实交互式 claude 终端**，互不干扰。

### 新建 / 编辑表单字段

| 字段 | 说明 |
| --- | --- |
| **名称**（可选） | 显示名；留空则对话出现第一条提问后**自动以提问内容命名** |
| **本地工作目录** cwd | claude 进程从该目录启动（`cd` 后运行）；旁有「选择…」按钮调系统目录选择器；会话页内新建默认沿用当前会话目录 |
| **Claude 参数** | 一排 `--flag`（每行一个，支持引号与 `#` 注释），追加给 claude 启动；如 `--model claude-sonnet-5`、`--allowedTools "Bash" "Read"`；`-p` / `--resume` / `--output-format` 由系统管理，不可写 |
| **跳过权限确认** | 勾选 = 带 `--dangerously-skip-permissions`，claude 自动执行工具不再逐条问你（**新建默认勾选**） |

按钮：「创建并进入对话」（新建）/「保存修改」（编辑）。

### 会话页布局

自上而下：

1. **多会话 tab 栏**：首位「◧ 工作空间」（回列表），其后是已打开的会话 tab（带运行状态点：绿闪 = 工作中 / 黄 = 空闲 / 灰 = 未运行），右侧「＋ 新建」可在当前目录基础上再开新会话
2. **会话工具条**：「⇤ 会话」返回、会话名 + `📁 工作目录`、运行中标签 + 「■ 结束终端」（未运行则显示「⟳ 重连」）、右侧「🧰 工具 / 📋 纪要」面板切换按钮
3. **主体区**：左侧真实终端，右侧 1/3 是面板（工具 / 纪要二选一，偏好记忆在本地）

### 多会话标签页

- 每个已打开的会话一个 tab，点击即切换（**不中断终端进程**）
- tab 状态记忆在本地，**重启应用可恢复**;最多保留最近 10 个
- tab 上「✕」关闭：若该会话终端仍在运行会提示"关闭标签不会结束终端进程",对话框中关闭当前 tab 会回到列表

## 5. 真实终端（对话主界面）

进入会话页即自动打开/附着该会话的**真实交互式 claude 终端**（每次一条带 TTY 的真实进程），对话体验与命令行里的 claude 100% 一致。

### 打开 / 附着

- 进入会话页会自动 `terminalOpen`：在该会话**工作目录**、套用其**启动参数**，起真实 claude TUI
- 打开是**幂等**的：会话终端已在运行（切了标签页/页面再回来）会无缝重附着，先把这之前的输出回放、再补到达的实时字节
- **切换标签页/离开页面不会中断终端**——多会话终端可以并行常驻

### 关闭 / 重连

只有三处会真正杀掉 claude 进程：

1. 顶栏「■ 结束终端」按钮（带确认弹窗，同时关闭该标签页）
2. 删除该会话
3. 应用退出

若 claude 进程自行退出（如 `Ctrl+C`），终端底部出现提示条「■ 进程已结束（Ctrl+C 等可能使 claude 退出）+ ⟳ 重连」，顶栏「结束终端」也会变「⟳ 重连」，点击重新拉起一个真实 claude。

### 字体大小

在「设置 → 终端 → 终端字体大小」里调（10–24 px，默认 13），改动**即时生效**并自动重新适配行列。窗口级还有 `F11` 全屏。

### 斜杠命令

**全部由 claude TUI 原生处理**，应用只做字节透传，不做任何解析——所以 `/retry`、`/rewind`、`/clear`、`/context`、`/compact`、`/resume`、`/memory`、`/status`、`/cost`、`/stats`、`/init`、`/model` 等与命令行行为一致（权限确认、状态栏原汁原味）。

其中 `/compact`（压缩上下文）有一个便利流程：应用发送后会**自动轮询确认提示并替你回 `y`**；个别版本文案不同抓不到提示时，会留给你在终端里自己回车确认，不破坏会话。

### 历史回看与滚动

TUI 全屏（alternate screen）下 xterm 不保留滚动历史，因此应用**自己保存剥离 ANSI 后的行历史（上限 3000 行）**：

- 滚轮上滚进入「↑ 历史回看」，提示"滚轮到底 / 按任意键返回实时"
- 右下角有自绘细滚动条，可拖动定位

### 复制 / 粘贴

应用自绘了终端右键菜单,并劫持了常用快捷键(经主进程剪贴板写入真实 claude 终端),`Ctrl+C` 仍原样留给 claude 当中断信号,不占用:

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| **粘贴** | `Ctrl/Cmd+V` / `Ctrl+Shift+V` / `Shift+Insert` | 把系统剪贴板文本写入终端输入行(多行自动逐行提交) |
| **复制** | `Ctrl/Cmd+Shift+C` / 右键「复制」 | 有选区复制选区;claude TUI 整屏重绘选不中时自动兜底为「复制整屏」 |
| **复制整屏** | 右键菜单「🖼 复制整屏」 | 直接复制终端最近一屏文字(claude 的完整回答常用这个) |

> 终端区域右键会弹出「📋 复制 / 🖼 复制整屏 / 📥 粘贴」菜单(与应用其它弹窗统一风格),点菜单外任意处关闭。以前「依赖 xterm 浏览器默认、输入法可能抢键位」的粘贴问题已修复。

## 6. 上下文监控

位置：会话页右侧「🧰 工具」面板的**底部**（工具面板默认打开，偏好记忆在本地）。实时显示当前会话的上下文占用，避免不知不觉顶到窗口上限。

### 指标

- **已用 / 窗口上限 / 百分比**：如 `58K/200K (29%)`（≥1000 用 K，≥1M 用 M）
- **彩色占比条 + 分级预警**：≥75% 红色、≥50% 黄色、其余绿色；≥75% 额外提示「⚠ 接近上限，建议 /compact 压缩上下文」
- **缓存命中率**：数据为「精确」档时显示（jsonl 的 `cache/(input+cache)`）
- **数据来源徽标**：`精确`（jsonl 真值） / `claude`（命令行 `/context` 实测） / `估算`
- **手动上限**：面板底部可输入 `200000` / `240k` / `1m` 指定窗口上限，留空按模型自动解析；格式错误会红字提示

### 数据怎么来的

主进程直接读取该 claude 会话的 usage 记录（jsonl）：

1. **精确优先**：过滤掉恒定占位的假值，取最后有效的 input+cache 真值
2. **估算兜底**：统计最近一次压缩标记之后的真实消息文本量（约 1 文本/3 token + 系统开销约 35K）；**`/compact` 或自动压缩后估算值会自动回落**
3. 上限按模型名解析（`[1m]`/`[240k]` 等优先，缺省 200K）

### 刷新

- 默认每 **2 秒**自动轮询
- 点工具面板「/context」按钮会用 claude 命令行实测读数并**锁定**（更可信）：面板显示「claude /context 实测读数(xx%)」+「恢复自动」，点「恢复自动」回到轮询

## 7. 会话纪要 & AI 总结

会话页顶栏「📋 纪要」展开右侧纪要面板，面板内「✨ 总结 / 📜 实录」两个视图互斥切换。它是独立的**右侧栏**，和「🧰 工具」面板（命令快捷 + 监控）二选一显示。

### 实录捕获

真实终端的所有输出会被**剥离 ANSI、节流落盘**为会话实录（每 6 秒落盘一次，为追加式，可回顾完整对话过程）。

- 实录视图按行分类排版：「你:」（原文 `❯ ` 前缀行）、正文、时间分隔
- 运行中每 4 秒刷新，未上翻时自动贴底跟随

### 「问完答完才总结」的触发

自动总结不是定时跑，而是按语义判断**这一轮问答结束了**才摘一次，同时满足三个条件：

1. **用户真的提交过提问**：输入里带回车才算（`❯` 提问行），且是新一轮、未被总结过
2. **这轮有实际回答**：累计输出 ≥100 字节才算活动输出（状态栏之类的小字节不算）
3. **这轮输出已停滞**：距最近一次终端输出超过 8 秒（视为 claude 答完/空闲）

终端退出/重开时也会补摘一次（增量）。

### 总结内容

底部交给**真实 claude** 生成（不是本地模板），逐条输出：

```
【14:32】👤 用户问题
🤖 回答要旨（一两句话，提炼结论/关键点）
```

只认实录里 `❯` 开头的行作提问；claude 自己发的确认/追问并入最近的回答；每条带时间。已有纪要时只把**新增段落**追加合并（增量），不整体重来。

### 手动入口

- 无总结但有内容：「✦ 生成总结」
- 已有总结：「↻ 重新总结」（全量重生成）
- 失败：「重试生成」
- 打开面板先秒显已存纪要，再自动补一次增量（没有新增时主进程直接返回缓存，不重复调 claude）

## 8. 对话队列

「🧰 工具」面板里的 **「/tunnel 对话队列（逐条自动接力）」** 按钮：点它不是发终端命令，而是**弹出队列对话框**——把多条问题排队，一条条自动喂给 claude，答完一条自动发下一条。

### 队列是什么

- **逐条多行文本**，条目状态：`待发 / 发送中 / 已完成`
- 数量**无上限**；条目**持久化**在会话文件里，重启应用仍在
- 执行状态在内存：重启后回到「未运行」，需要再点开始

### 操作

- 输入框：回车 = 添加一条，`Shift+Enter` = 换行；行内 ✎ 编辑、🗑 删除
- **▶ 开始**：所有条目复位为待发，从队首逐条发送；每答完一条自动发下一条，全部完成自动停止
- **⏸ 暂停**：正在答的那条答完即停，不再续发；再次开始**从头重跑**（已完成的仍标记完成）
- **停止**：立即清运行态；**终端进程退出会自动停队列**，避免对着空终端续发
- 运行中禁止增删改队列（提示"队列正在执行，请先暂停再修改"）；发送失败（如终端未运行）自动停止并保留该条为待发
- 关闭对话框只收起面板，队列内容保留，随时可再开

## 9. 设置项详解

### 9.1 界面主题

暗色 / 亮色，即时生效；沿用至下次启动。Windows 下原生标题栏颜色跟随。

### 9.2 关闭行为

- **退出**（默认）：点 X = 关闭程序，有终端时先弹确认框
- **缩小到托盘**：点 X = 藏到托盘继续运行，托盘图标恢复，托盘菜单「退出」才真正退出

### 9.3 终端字体

真实终端（xterm）的字号，10–24 px，改动即时生效，默认 13。

### 9.4 claude 可执行文件

- 留空 → 自动发现 PATH 里的 `claude`
- 可手动填路径（Windows 通常为 `%APPDATA%\npm\claude.cmd`）
- **测试**：探测输入路径是否可用并显示版本
- **更新**：执行 `claude update`（耗时较长）
- **📖 claude 安装指南**：打开在线安装文档
- 设置页会展示实际使用的二进制路径与版本号，以及落盘日志路径（排查问题用）

### 9.5 命名配置模板

把常用「配置名 + 内容」存成模板（存于应用自己的 userData，不碰你的真实配置），随时：

- **＋ 新建命名配置**：命名 + 填 JSON/Markdown 内容（带语法高亮）
- **使用 / 下拉应用**：一键把模板内容写入 `~/.claude/settings.json` 并立即生效
- 编辑 / 删除模板

适合把一组「hooks / MCP / system prompt」打包成一个环境配置，按项目一键切换。

### 9.6 Claude 配置文件（直接编辑）

只允许读写真实 claude 的**白名单三件套**（其它路径一律禁止）：

| 文件 | 作用 |
| --- | --- |
| `settings.json` | 全局配置（环境变量 / hooks / MCP / 权限） |
| `settings.local.json` | 本机私密配置（令牌等，不随项目走） |
| `CLAUDE.md` | 项目级指令 |

- 点击列表项载入编辑区（JSON 自动校验格式、语法高亮；`.md` 按 Markdown 高亮；**原子写入**）
- 保存后**底层 claude 下次调用即生效**
- 未创建的文件显示「（未创建）」，可直接新建

### 9.7 关于

底部展示应用名与版本号。

## 10. 常见问题（FAQ）

### 10.1 启动后一直停在启动页（转圈）不进入主界面？

前端静态资源没生成或缺失。用源码启动请先 `npm run build` 再 `npm start`（或直接用 `npm run app`，它会先构建再启动）。正式发布包不含此问题。

### 10.2 打开会话提示"终端未运行/工作目录不存在"？

- 工作目录不存在：新建/编辑会话时把 cwd 指到真实存在的项目目录（可用「选择…」目录选择器）
- 提示找不到 claude：见下条

### 10.3 提示找不到 claude / 会话起不来？

应用依赖真实的 `claude` CLI。确认：

1. 命令行里 `claude --version` 能跑（已安装且在 PATH）
2. 或在「设置 → claude 可执行文件」填入明确路径（Windows 常为 `%APPDATA%\npm\claude.cmd`），点「测试」验证，再「保存」
3. Windows 上建议用官方安装器装（见设置页里的「📖 claude 安装指南」）

### 10.4 退出时提示"还有 N 个终端正在运行"？

这是**防误关保护**：说明有真实 claude 会话还在跑。点「确定关闭」才会终止这些终端并退出；选「取消」继续用。若常驻后台使用，可改「设置 → 关闭行为 → 缩小到托盘」——那样点 X 直接藏起来、终端不停。

### 10.5 点 X 窗口消失但程序没退？

你已开启「关闭行为 → 缩小到托盘」：窗口藏到系统托盘继续运行。左键单击**托盘图标**恢复，托盘右键「退出」彻底关闭。

### 10.6 面板数据显示「估算」「claude 实测」是什么意思？

上下文占用有多个数据来源（详见第 6 章）：`精确` = 读 usage 记录的真值；`估算` = 按实录文本量的近似值（压缩后会自动回落）；`claude` = 点「/context」命令拿 claude 自己报的实测。想拿最准的数，用「/context」实测并锁定。

### 10.7 关闭确认框 / 弹窗样式和系统不一致？

Claude Desk 的确认框是**应用自绘**的（与应用内其它弹窗统一风格），不是系统原生框，这是设计使然。Esc 取消、Enter 确认。

### 10.8 主题切换后 Windows 标题栏还是白的？

暗色主题下标题栏应深色跟随。若仍是白色，大概率跑的是旧版/旧打包产物——升级到包含「窗口级主题同步」的版本再试。

### 10.9 日志在哪看？

「设置 → claude 可执行文件」下方会显示落盘日志路径（`userData/claude-desk.log`）。排查启动、会话、窗口类问题先看它；界面里也有日志路径展示。

### 10.10 数据存在哪？

全部本地：会话/设置/命名模板存在应用 userData 目录；真实 claude 自己的会话/配置按 claude 规则存放（`~/.claude/`）。**不联网上传**（除调用 claude 本身）。

### 10.11 源码启动想看启动页效果？

本地源码启动时启动页通常一闪而过（几百毫秒）。可带环境变量 `CD_SPLASH_MS=4000 npm start` 让它多停 4 秒用于确认；正式运行不要加（会拖慢进入）。

### 10.12 打包发布

```bash
npm run dist:linux   # Ubuntu: AppImage / tar.gz
npm run dist:win     # Windows: portable exe / zip
```

产物在 `dist/`（需先有 `claude` CLI 与对应平台的 node-pty prebuilt）。具体见 `README.md`。
